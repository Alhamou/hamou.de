## ما هو Haki؟

Haki (حكي) تطبيق أصلي خفيف في شريط قوائم macOS لتحويل الكلام إلى نص. انقر في أي حقل نصي في أي تطبيق، واضغط اختصار الضغط والتحدث مطوّلًا، وتحدث ثم اترك. ينسخ Haki ما قلته نصًّا ويلصقه عند المؤشر. وشعاره: «احكي، وحكي بيكتبها».

صُمم خصوصًا للعربية الطبيعية واللهجة الشامية، مع دعم الإنجليزية والألمانية والفرنسية والتعرف التلقائي على اللغة. ليس فيه نموذج كلام محلي ولا بيئة Python أو Node.js: التطبيق Swift أصلي، والتحويل تقوم به OpenAI.

## كيف يعمل الإملاء

1. ركّز على حقل نصي في أي تطبيق، مثل الملاحظات أو TextEdit أو متصفح أو تطبيق محادثة أو محرر.
2. اضغط `⌥ Option + Space` مطوّلًا وتحدث.
3. اترك المفتاحين. يرسل Haki التسجيل إلى OpenAI ويستلم النص ويلصقه عند المؤشر.

يحفظ Haki حافظتك قبل اللصق ويستعيدها بعده، ويفعل ذلك دون أن ينتزع التركيز من التطبيق الذي تكتب فيه. ومؤشر عائم صغير يبيّن هل يسجّل الآن أم يحوّل أم انتهى. أما النقرات العرضية التي تقل عن ثلث ثانية تقريبًا فتُهمل محليًا.

## اللغات والنماذج

- **اللغات:** العربية (مع تحسين للهجتين الشامية والسورية)، والإنجليزية، والألمانية، والفرنسية، أو التعرف التلقائي.
- **النماذج:** `gpt-transcribe` هو الافتراضي وموجّه للكتابة الصوتية اليومية السريعة منخفضة التأخير. و`gpt-4o-transcribe` خيار أعلى دقة للعبارات المعقدة واللهجات والمصطلحات التقنية. تبدّل من الإعدادات أو من شريط القوائم.
- **الميكروفونات:** اختر الميكروفون المدمج أو واجهة USB أو AirPods. يتولى Haki إعادة الاتصال عبر CoreAudio ويمكنه تفضيل AirPods عند اتصالها. ومقياس مستوى حي يتيح لك اختبار الإدخال.

## الخصوصية: ما يبقى على جهازك وما يذهب إلى OpenAI

كن واضحًا بشأن المقايضة: **تسجيلاتك الصوتية تُرسل إلى OpenAI.** وبحسب README تذهب مباشرة من جهازك إلى نقطة التفريغ الصوتي لدى OpenAI عبر TLS بلا خوادم وسيطة، لذلك يحتاج الإملاء إلى اتصال بالإنترنت وإلى مفتاح OpenAI API الخاص بك، ويُستخدم وفق شروط OpenAI وأسعارها.

وعلى جهازك يقول README إن Haki لا يضمّن أي تحليلات أو تشخيصات أو تقارير أعطال أو حزم SDK من أطراف أخرى. يُسجَّل الصوت في ملفات مؤقتة ويُحذف فور انتهاء التحويل أو فشله، فلا يُحتفظ بسجل صوتي. ويُخزَّن مفتاح API في سلسلة مفاتيح macOS (Keychain) وليس في التفضيلات أو ملفات الإعداد أو السجلات.

## الأذونات

- **الميكروفون:** لالتقاط صوتك، وفقط ما دمت تضغط الاختصار أو تبدأ الإملاء من القائمة.
- **إمكانية الوصول (Accessibility):** للاختصار العام للضغط والتحدث ولإدراج النص بمحاكاة `⌘V`. وبحسب README لا يلزم إذن «مراقبة الإدخال» (Input Monitoring) بشكل منفصل.

## الإعداد

1. افتح Haki. اسمح بالوصول إلى الميكروفون حين يسأل macOS، وفعّل Haki ضمن إعدادات النظام، ثم الخصوصية والأمان، ثم «إمكانية الوصول».
2. افتح الإعدادات من أيقونة شريط القوائم أو بـ `⌘,`. في تبويب Transcription الصق مفتاح OpenAI API واختر Save ثم Test API Key.
3. اختر نموذجًا، وفي تبويب Audio اختر الميكروفون.

## الإملاء من آيفون عبر AirMouse

[AirMouse](https://github.com/Alhamou/AirMouse) تطبيق مفتوح المصدر مستقل يحوّل آيفون إلى لوحة تتبّع لجهاز ماك عبر شبكة Wi-Fi المحلية. يسجّل تبويبه الصوتي على الهاتف ويسلّم الصوت إلى Haki الذي يكتب النص على جهاز ماك. يجب أن يكون Haki مثبّتًا وقيد التشغيل، ويستخدم مفتاح API المعتاد وإعدادات النموذج واللغة لديك.

التسليم بسيط ومفتوح لمرسِلين آخرين أيضًا. يُكتب تسجيل (`m4a` أو `mp4` أو `webm` أو `wav` أو `mp3` أو `ogg`، حتى 25 ميغابايت) في `~/Library/Caches/Haki/Inbox/`، ثم يُفتح الرابط `haki://transcribe?file=<اسم الملف>`. يحوّل Haki الملف إلى نص ويلصقه ويحذف الملف. ولا تُقبل إلا أسماء الملفات البسيطة داخل صندوق الوارد، فتُرفض المسارات والملفات المخفية والروابط الرمزية.

## ابنِه بنفسك

يحتاج Haki إلى macOS 13 Ventura أو أحدث، على Apple silicon أو Intel، وإلى أدوات سطر الأوامر لـ Xcode مع Swift 6.0 أو أحدث. انسخ المستودع من GitHub وشغّل `swift test` ثم `./scripts/build_app.sh`. يبني السكربت الملف التنفيذي للإصدار، ويجمّع `Haki.app`، ويوقّعه بشهادة Apple Development المحلية لديك أو بتوقيع مؤقت (ad hoc)، ويثبّته في `/Applications`.

## مفتوح المصدر

صدر Haki بترخيص MIT. يشترط دليل المساهمة ألا تُضاف نماذج محلية ولا Python ولا Node.js ولا Electron، وألا تُرفع مفاتيح API أبدًا. ينشر عماد الحمو، صاحب هذا الموقع، Haki على [GitHub](https://github.com/Alhamou/Haki). تقارير الأخطاء وطلبات الدمج (Pull Requests) مرحّب بها، والمخاوف الأمنية تُبلَّغ وفق سياسة الأمان في المستودع.

## الأسئلة الشائعة

### ما هو Haki؟

Haki تطبيق مفتوح المصدر في شريط قوائم macOS للإملاء الصوتي بالضغط والتحدث. اضغط `⌥ Option + Space` مطوّلًا وتحدث ثم اترك، فيُلصق النص المحوَّل عند المؤشر في أي تطبيق. هو مضبوط للعربية ويدعم أيضًا الإنجليزية والألمانية والفرنسية.

### كيف أُملي بـ Haki؟

انقر في حقل نصي، واضغط `⌥ Option + Space` مطوّلًا، وتحدث، ثم اترك. يرسل Haki التسجيل إلى OpenAI ويلصق النص عند المؤشر.

### ما اللغات والنماذج التي يدعمها Haki؟

العربية (مع تحسين للهجتين الشامية والسورية)، والإنجليزية، والألمانية، والفرنسية، والتعرف التلقائي. والنماذج هي `gpt-transcribe` وهو الافتراضي، و`gpt-4o-transcribe` لدقة أعلى.

### هل يرسل Haki صوتي إلى OpenAI؟

نعم. التحويل تقوم به OpenAI، لذلك يُرسل كل تسجيل من جهازك مباشرة إلى OpenAI عبر TLS. ويحذف Haki ملف الصوت المؤقت فور انتهاء التحويل أو فشله، ولا يحتفظ بسجل صوتي.

### هل أحتاج إلى مفتاح OpenAI API؟

نعم. يستخدم Haki مفتاح OpenAI API الخاص بك، ويخزّنه في سلسلة مفاتيح macOS. والاستخدام وفق شروط OpenAI وأسعارها.

### ما الأذونات التي يحتاجها Haki؟

الميكروفون لالتقاط صوتك ما دمت تضغط الاختصار، وإمكانية الوصول للاختصار العام وللصق بمحاكاة `⌘V`.

### ما أجهزة ماك وإصدارات macOS المدعومة؟

macOS 13 Ventura أو أحدث، على Apple silicon أو Intel. والبناء يحتاج إلى Swift 6.0 أو أحدث.

### هل أستطيع الإملاء من آيفون؟

نعم، عبر AirMouse، وهو تطبيق مرافق مفتوح المصدر. يسجّل تبويبه الصوتي على الهاتف ويكتب Haki النص على جهاز ماك. يجب أن يكون Haki مثبّتًا وقيد التشغيل.
